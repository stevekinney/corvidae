# Protected MCP HTTP

`@lostgradient/mcp/http` wraps a Fetch dispatcher with protected-resource discovery and bearer admission. Configure a canonical HTTPS origin, resource path, external issuer, advertised scopes, a verifier, and a current-principal resolver. The verifier must authenticate the token using the issuer's keys or authenticated introspection and return its issuer, audience, subject, scopes, and expiration in Unix milliseconds. The principal resolver must consult current membership and return its delegable scopes. The handler checks the configured issuer, audience, and expiration and does not accept cookies or API keys as bearer credentials.

The dispatcher receives the verified grant and principal. Before invoking an operation, call `context.requireScopes(requiredScopes)` and return its response when it refuses. A missing scope produces an upgrade challenge only when the principal can delegate it. The dispatcher owns operation authorization and must propagate the request's cancellation signal to its work. Response streams are cancelled on client cancellation and their chunks are released only while the token and membership remain current. Public discovery URLs always use the configured origin, never forwarded host headers. `allowedOrigins` admits browser origins; by default no browser origin is admitted. `maximumRequestBytes` bounds request bodies and defaults to one mebibyte.
