# Bureau client

`@lostgradient/bureau-client/reviews` provides a generated, browser-safe Reviews client bound to a host-supplied catalog transport. The optional `reviews/svelte` entry supplies scoped Svelte bindings, and `reviews/ui` provides the shared approval controls.

Generate the client with `bun run --cwd packages/bureau-client generate`. Run its tests with `bun run --cwd packages/bureau-client test`.
