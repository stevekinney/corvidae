# @lostgradient/chart

This package holds the `area-chart`, `bar-chart`, `donut-chart`, `line-chart`, `matrix-chart`, `sparkbar`, `spectrogram`, `spectrum-chart`, `waveform` components, which the Cinder package split (P-COR-101) moved out of `@lostgradient/cinder`. `@lostgradient/cinder` re-exports what it holds.
